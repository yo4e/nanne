# nanne ネーミングレビュー

調査日: 2026-08-16

## この文書の位置づけ

Issue #1 に基づく公開前の簡易ネーミング調査です。検索エンジン、GitHub、アプリストア検索、J-PlatPat、ドメインWHOISを組み合わせています。検索結果に現れなかったことは、商標・商号・サービス名の安全性を保証しません。公開・有料化・商標登録の前には、弁理士による先行商標調査を行ってください。

## 結論

現時点では、名称を直ちに変更する必要があるとまでは判断しません。暫定的には、nanne をブランド名として残し、サービス説明を添えて nanne chat または nanne — temporary chat のように使う案を推奨します。

ただし、次の理由から「商標上安全」「完全に空いている」とは言えません。

- J-PlatPatで、ＮＡＮＮＥ／ナンネの登録商標が1件確認できた。
- nanne.com は登録済みで、標準ドメインの取得候補にはできない。
- GitHubには同名・類似のアカウントやリポジトリが複数ある。
- 検索エンジンやアプリストアに、同名の著名チャットサービスは目立って確認できなかったが、検索結果は網羅的ではない。
- 「なんね？」という日本語の由来は親しみやすい一方、海外利用者には意味が伝わらないため、説明語を付けた方が識別しやすい。

## 1. 商標調査

### J-PlatPatで確認できた登録

2026-08-16 に、J-PlatPatの商標検索で次の条件を指定しました。

- 商標（検索用）: nanne
- 称呼（単純文字列検索）: ナンネ
- 部分一致

確認できた結果は次の1件です。

| 項目 | 結果 |

| 商標 | ＮＡＮＮＥ |
| 登録番号 | 5483611 |
| 出願番号 | 商願2011-082203 |
| 称呼 | ナンネ |
| 区分 | 29、32 |
| 権利者表示 | 株式会社野口総合研究所 |
| 状態 | 存続-登録-継続 |
| 出願日 / 登録日 | 2011-11-01 / 2012-04-06 |

検索結果上の区分は29、32で、nanneのソフトウェア・通信サービスと直ちに同一とは限りません。しかし、類似判断は文字だけでなく、指定商品・役務、取引実情、称呼・外観・観念を総合して行われます。区分が違うことだけで安全とは判断しません。

今回の検索は、入力した文字列と称呼に対する再現可能な一次確認です。異字体、類似称呼、別区分、未登録表示、海外権利、会社名・ドメイン名までは網羅していません。

- [J-PlatPat 商標検索](https://www.j-platpat.inpit.go.jp/t0100)

### 追加で行うべき確認

公開前、特に有料化・広告・商標登録を行う前に、少なくとも次を専門家または追加検索で確認します。

- ソフトウェア、ダウンロードアプリ、通信、SaaSに関係する区分
- nanne、ＮＡＮＮＥ、ナンネ、および外観・称呼が近い名称
- 既存の商号、サービス名、アプリ名、ドメイン、SNSアカウント
- 日本以外で提供する場合の各国商標
- nanne chat のように説明語を加えた場合の識別力と先行権利

## 2. サービス名・アプリ・GitHubの確認

### 著名な同名サービス

検索エンジンで nanne / Nanne と chat、messaging、SaaS、アプリを組み合わせて確認した範囲では、nanneという名称の著名な同名チャットサービスやSaaSは確認できませんでした。アプリストア検索でも、同名の著名チャットアプリは目立って確認できませんでした。

一方、Nanneは人名としても使われ、無関係なアプリ開発者名・プロフィール名などが検索結果に出ます。これらは直ちにサービス名の衝突を意味しませんが、検索性とSEOではノイズになります。

### GitHub

GitHubのリポジトリ検索では、nanneという名前のリポジトリやユーザーが複数確認できました。nanne chat の検索では、現時点では yo4e/nanne が主な該当結果でした。

- [GitHub: nanne リポジトリ検索](https://github.com/search?q=nanne&type=repositories)
- [GitHub: nanne chat リポジトリ検索](https://github.com/search?q=nanne+chat&type=repositories)

これはGitHub上で名前が唯一であることを意味しません。README、パッケージ名、SNSの表示名、検索用の説明語に chat / temporary / invite-only などを添えると、混同と検索ノイズを下げられます。

## 3. ドメイン・SNS

### ドメイン

nanne.com はWHOIS確認時点で登録済みでした。したがって、nanne.comを取得できる前提でブランドを設計しないでください。

- [WHOIS: nanne.com](https://who.is/whois/nanne.com)

nanne.jp、nanne.io、nanne.appなどの空き状況は、レジストラ、登録要件、プレミアム価格、取得時点により変動するため、この調査では確定判定していません。購入直前に公式レジストラで確認し、利用規約・商標・なりすましリスクも合わせて確認します。

### SNS

主要検索エンジンで nanne と chat / app を組み合わせて確認した範囲では、同名の著名チャットブランドは確認できませんでした。ただし、SNSのアカウント取得状況や非公開アカウントは検索結果だけでは判定できません。公開前に、公式アカウント名、プロフィール、短縮URL、なりすまし通報先を確保してください。

## 4. 推奨判断

### 現時点の案

1. v1では nanne を残し、nanne chat のような説明語を付ける。
2. ロゴ、ドメイン、SNS、アプリ表示では、単独のnanneだけに依存せず、一時チャット・招待制・テキストのみ等の説明を併記する。
3. 有料化、広告、一般公開、アプリストア申請、商標出願の前に、弁理士へ区分を指定した先行商標調査を依頼する。
4. nanne.comを前提にせず、取得可能なドメインとSNSハンドルを先に確認する。
5. 既存のＮＡＮＮＥ登録商標との関係について、指定区分が異なることを根拠に自己判断で安全宣言しない。

### 改名を検討する条件

次のいずれかが見つかった場合は、nanneを維持するより改名を優先します。

- ソフトウェア・通信・SaaSに近い区分で同一または強く類似する商標がある
- 同名のチャット・コミュニケーションサービスが日本または提供予定地域で営業している
- 公式ドメインやSNSハンドルを確保できず、なりすまし・誤認のリスクが高い
- 海外利用者向けに、発音・意味・検索性の説明コストがブランド上の利点を上回る
