## 結論

現時点では、`nanne` を直ちに改名すべき強い衝突は確認できていません。ただし、`nanne` と同一の日本商標登録記録が少なくとも1件あり、`.com` はすでに登録済みです。また、短い単語で人名にも用いられるため、検索性・識別性・ドメイン確保の面で単独表記には限界があります。[1] [2]

**v1では、ブランドの核として `nanne` を残しつつ、画面表示・説明文・リポジトリ説明では `nanne — temporary chat` のような説明語を併記する**ことを勧めます。これは商標上の衝突を自動的に解消する方法ではなく、利用者の混同と検索ノイズを下げるための表示上の方針です。アプリ配信、有料化、広告導入、商標出願の前には、名称そのものを維持できるかを専門調査で決めてください。

## 1. 調査方法と限界

特許庁は、J-PlatPatの「称呼（類似検索）」で読み方が類似する可能性のある商標を広く確認し、「商標（検索用）」で同じ文字を含む商標を確認する方法を案内しています。検索項目・キーワードを変えること、情報反映に時差があり得ることも明示されています。[1]

今回、J-PlatPatの簡易検索で登録番号 **5483611** を照会し、商標出願 **2011-082203** と商標公報 **5483611** の対応を確認しました。[2] ただし、簡易検索は詳細検索の代替ではありません。また、ブラウザのセッションに依存する詳細画面から、今回の調査時点で指定区分、権利者、現存続状態を再取得・再確認することはできませんでした。既存の資料にあった区分・権利者・状態は、**この改訂版では再検証済みの事実として扱いません**。

この調査は、`nanne`、`Nanne`、`NANNE`、`ナンネ` を中心にした公開Web・GitHub・公式DBの初期確認です。類似称呼、異表記、図形、指定商品・役務、未登録周知表示、商号、不正競争、各国権利、将来の出願は網羅していません。

## 3. Webサービス・アプリ・GitHub

公開Web検索では、`nanne` の語が人名・プロフィール名などとしても使われるため、検索結果にノイズがあります。この調査時点で、日本で広く知られた同名のチャット・メッセージングサービスとの明確な衝突は確認できませんでした。しかし、検索結果に現れないサービス、地域限定のサービス、アプリストアの表示名、未公開プロダクトがあり得るため、「見つからない」ことを安全宣言には使えません。

## 4. ドメイン・SNS

VerisignのRDAP記録では、`NANNE.COM` は登録済みで、2026-08-18時点のレコードには有効期限が2026-12-10と記載されています。[4] これはドメインの登録状況に関する参考情報であり、登録者との関係、実際のサービス内容、商標上の関係を示すものではありません。

`.jp`、`.io`、`.app`その他の候補は、登録要件・価格・プレミアム設定・取得可否が変動します。取得可能であること自体は商標上の使用可能性を保証しません。公開時に使う**1つの公式ドメイン**、主要SNSの公式ハンドル、なりすまし報告の窓口を決め、利用規約・プライバシー通知・READMEで一貫して表示してください。

## 5. 推奨判断

現段階の判断は、**「`nanne` をv1のブランドとして維持し、説明語を併記する。ただし、収益化・アプリ化・海外展開・商標出願の前に専門的な先行調査を完了する」**です。

この判断は、`nanne` に一切の衝突がないという意味ではありません。日本の同一登録記録と、`.com` が利用できない事実により、単独語を長期的な独占ブランドとして扱うには不確実性があります。一方で、今回の公開調査では、直ちに改名を要するほど明確な国内チャットサービスの衝突は確認できませんでした。

| 状況 | 推奨アクション |
| --- | --- |
| 無料・小規模なWeb版v1 | `nanne` を維持し、説明語を併記する。公式ドメインと問い合わせ先を確保する。 |
| 有料化・広告・スポンサー | 弁理士に、実際の役務と対象区分を指定した先行調査を依頼する。 |
| アプリストア公開 | ストア検索と審査ポリシーを国別に確認し、開発者名・アイコン・説明文の混同も避ける。 |
| 海外提供 | WIPOおよび対象国の公式DBを使い、現地の商標専門家を含めて再評価する。 |
| 近い区分の強い先行商標・同名通信サービスが見つかった場合 | `nanne` 単独利用を停止し、改名または専門家の意見に基づく対応を優先する。 |
